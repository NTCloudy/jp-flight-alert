🔑 第一次使用：連結你的 GitHub

不登入也能看機票；要修改設定、暫停通知或按上面的按鈕，需要一組只能存取這個專案的 GitHub 金鑰（設定一次就好，金鑰只存在這台裝置的瀏覽器裡）。
  1. 點這裡 → 建立 GitHub 金鑰（已幫你預填好權限）
  2. Repository access 選 Only select repositories → 選 jp-flight-alert
  3. 確認 Permissions 有 Contents：Read and write、Actions：Read and write
  4. 按 Generate token，把 github_pat_ 開頭的金鑰貼到下面

💡 也可以沿用高鐵控制台那組金鑰：到 GitHub 金鑰設定 編輯它，把 jp-flight-alert 也勾進去，再貼到這裡。
